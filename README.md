# team-final-project
Учебный проект: сортировка кастомных объектов


## Реализация трёх способов заполнения массива
- `input/DataSource.java` — интерфейс-стратегия, один метод `load(int size)`.

- `input/ManualDataSource.java` — реализация для ручного ввода. У неё два вспомогательных метода: `readValidTextField` (для строкового поля `title`) и `readValidIntField` (сначала ловит `NumberFormatException` при нечисловом вводе, затем проверяет диапазон через `ValidationException`). Оба переспрашивают только то поле, где произошла ошибка.

- `validation/MovieValidator.java`, `ValidationException.java` — три метода проверки по одному на поле плюс общий `validate(Movie)`.
Год проверяется диапазоном `[1888, текущий год + 1]` (нижняя граница — год первого сохранившегося фильма, верхняя вычисляется через `Year.now()`, а не зашита числом), продолжительность — диапазоном `[1, 600]` минут.
