# team-final-project
Учебный проект: сортировка кастомных объектов


## Реализация трёх способов заполнения массива
- `input/DataSource.java` — интерфейс-стратегия, один метод `load(int size)`.

- `input/ManualDataSource.java` — реализация для ручного ввода. Все поля считываются одним обобщённым методом `readField(prompt, parser, check)`: для `title` разбор не нужен, для года и продолжительности используется `Integer::parseInt`. Нечисловой ввод ловится как `NumberFormatException`, выход за диапазон — как `ValidationException`. Переспрашивается только то поле, где произошла ошибка.

- `input/FileDataSource.java` — реализация для чтения из текстового файла (UTF-8). Формат: одна строка на фильм, `Название;Год;Продолжительность`. Разделитель — `;`, чтобы в названии можно было писать запятые.
Пустые строки и строки, начинающиеся с `#`, пропускаются, BOM в начале файла отбрасывается.
Некорректная строка не останавливает загрузку: она пропускается с сообщением `Строка N пропущена: <причина>`.
Читается не больше `size` валидных фильмов. Если валидных строк меньше, возвращается массив меньшей длины, как и допускает контракт `DataSource`. Пример файла лежит в `data/movies.txt`.

- `input/RandomDataSource.java` — реализация для случайного заполнения. Название склеивается из двух случайных слов (`Тайна` + `океана`), второе слово в родительном падеже, поэтому любое сочетание звучит по-русски. Год выбирается от 1950 до 2025, продолжительность — от 60 до 200 минут. Эти границы лежат внутри правил `MovieValidator`, поэтому сгенерированные фильмы всегда валидны и отдельная проверка не нужна.

- `Main.java` — пользователь выбирает способ заполнения (вручную / из файла / случайно) и длину массива. Для файла запрашивается путь (Enter — `data/movies.txt`), и путь переспрашивается, пока не будет указан существующий файл.

- `validation/MovieValidator.java`, `ValidationException.java` — три метода проверки по одному на поле плюс общий `validate(Movie)`.
Год проверяется диапазоном `[1888, текущий год + 1]` (нижняя граница — год первого сохранившегося фильма, верхняя вычисляется через `Year.now()`, а не зашита числом), продолжительность — диапазоном `[1, 600]` минут.


## Как добавить новый способ
Делается как ещё один класс `implements DataSource`, больше в проекте
ничего менять не нужно.
